# Internship_report

Le fichier fixed_val_test.ipynb est le Jupiter notebook qui permet d'initialiser le modèle de réseaux de neurones et de l'entrainer qui a permis d'obtenir le meilleur résultat de performance sur la prédiction des forces de frottements.  
Il existe de nombreux commentaires dans le code. Ils permettent de tester différents modèles pour comparer les performances.

Le fichier input_bf_creator.ipynb est le fichier qui permet de créer une base de donnée dans un fichier .mat qui contient les consignes de vitesses utilent à la génération des données d'entrainement avec la simulation.
